FILMNOVA WINDOWS APP MODE

EXE -> API /api/app.php?action=launch -> server cấp launch URL có chữ ký -> app mở launch URL trong Edge App Mode -> server tạo phiên app -> index.php không hiển thị App Gate -> toàn bộ giao diện website hiện trong app.

Người dùng không nhập API URL/API Key.
Chỉ chủ web cấu hình SITE_URL + API_KEY trước khi compile.
